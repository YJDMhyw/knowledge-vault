# 知识掌中宝 - 产品需求文档

## 1. 产品概述

知识掌中宝是一款专注于概念与定义学习的记录应用，帮助用户系统性地管理和复习知识要点。通过科学的记忆和考核机制，提升学习效率。

**核心价值：**
- 结构化记录概念与定义，建立个人知识库
- 渐进式考核系统，强化记忆效果
- 简洁高效的多级导航，快速定位内容

**目标用户：**
- 学生群体：记录课堂知识点
- 专业人士：整理行业术语和概念
- 终身学习者：构建个人知识体系

## 2. 核心功能

### 2.1 功能模块概览

1. **主界面 (Home)**
   - 展示最近添加的概念
   - 显示学习统计数据
   - 快速进入考核模式

2. **目录界面 (Categories)**
   - 按类别管理概念
   - 支持多级目录结构
   - 概念的增删改查

3. **考核界面 (Quiz)**
   - 展示概念，用户回忆定义
   - 渐隐渐显动画切换
   - 记录考核结果

4. **内容管理界面 (Manage)**
   - 批量管理概念和类别
   - 导入导出功能
   - 数据统计

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|

| 主界面 | 最近添加 | 展示最近5条添加的概念卡片 |
| 主界面 | 快速操作 | 一键开始考核、添加新概念 |

## 3. 核心流程

### 3.1 添加概念流程

```
用户 → 内容管理界面 → 选择目录 → 输入概念 → 输入定义 → 保存
```

### 3.2 考核流程

```
开始考核 → 展示概念 → 用户输入 → 渐隐概念 + 渐显定义 → 判定对错 → 下一题
```

**渐隐渐显动画规格：**
- 渐隐时间：600ms，ease-out
- 渐显时间：600ms，ease-in
- 间隔：200ms
- 概念与定义使用相同位置切换

### 3.3 导航流程

```
主界面 ←→ 目录界面 ←→ 考核界面
              ↓
         内容管理界面
```

## 4. 用户界面设计

### 4.1 设计风格

**主题：墨韵书香**
- 文化底蕴：借鉴中国传统书法美学
- 现代简约：去除冗余装饰，聚焦内容
- 温和护眼：低饱和度配色，减少视觉疲劳

**色彩方案：**
- 主色：`#2D3436` (墨色)
- 次色：`#636E72` (灰墨)
- 强调色：`#00B894` (翠青 - 代表学习成长)
- 背景：`#FAFAFA` (宣纸白)
- 卡片背景：`#FFFFFF`
- 文字主色：`#2D3436`
- 文字次色：`#636E72`

**字体选择：**
- 标题：思源宋体 (Noto Serif SC) - 文化气息
- 正文：思源黑体 (Noto Sans SC) - 清晰易读
- 代码/术语：JetBrains Mono

**按钮风格：**
- 圆角：8px
- 悬停：轻微上浮 + 阴影加深
- 点击：轻微下沉

**布局风格：**
- 侧边导航 + 主内容区
- 卡片式内容展示
- 大量留白，呼吸感强

### 4.3 响应式设计

- 桌面端 (>1024px)：完整侧边栏 + 多列布局
- 平板端 (768-1024px)：折叠侧边栏 + 双列布局
- 移动端 (<768px)：底部导航 + 单列布局

### 4.4 动效设计

| 场景 | 动效类型 | 时长 | 缓动函数 |
|-----|---------|------|---------|
| 页面切换 | 淡入淡出 | 300ms | ease-in-out |
| 卡片悬停 | 上浮 + 阴影 | 200ms | ease-out |
| 概念渐隐 | 透明度 1→0 | 600ms | ease-out |
| 定义渐显 | 透明度 0→1 | 600ms | ease-in |
| 按钮点击 | 下沉 | 100ms | ease-out |
| 导航展开 | 高度变化 | 250ms | ease-out |

## 5. 数据结构

### 5.1 概念 (Concept)
```typescript
interface Concept {
  id: string;
  name: string;          // 概念名称
  definition: string;    // 定义内容
  categoryId: string;    // 所属类别ID
  createdAt: number;     // 创建时间戳
  updatedAt: number;     // 更新时间戳
  quizCount: number;     // 考核次数
  correctCount: number;  // 正确次数
}
```

### 5.2 类别 (Category)
```typescript
interface Category {
  id: string;
  name: string;          // 类别名称
  parentId: string | null; // 父级ID，null为顶级
  order: number;         // 排序顺序
  createdAt: number;
}
```

### 5.3 考核记录 (QuizRecord)
```typescript
interface QuizRecord {
  id: string;
  conceptId: string;
  userAnswer: string;
  isCorrect: boolean;
  timestamp: number;
}
```

## 6. 验收标准

1. ✅ 四个主要界面可正常切换
2. ✅ 多级目录导航正常工作
3. ✅ 可添加、编辑、删除概念
4. ✅ 考核时概念渐隐、定义渐显动画流畅
5. ✅ 数据持久化存储（localStorage）
6. ✅ 响应式布局适配不同设备
7. ✅ 动画效果符合规格要求
